# 💰 Lista de Gastos

Projeto desenvolvido durante os estudos de JavaScript (focado em manipulação de objetos, DOM e lógica de programação) no curso da **Rocketseat**.

## 🚀 Tecnologias Utilizadas

Este projeto foi construído utilizando as seguintes tecnologias:
* **HTML5** (Estruturação semântica)
* **CSS3** (Estilização responsiva e moderna)
* **JavaScript (ES6+)** (Lógica, manipulação de objetos, arrays e eventos do DOM)
* **Git & GitHub** (Controle de versão e hospedagem)

## 🎯 Funcionalidades

* **Cadastro de Despesas:** Adiciona novos itens informando nome, categoria e valor.
* **Manipulação de Objetos:** Utilização de estruturas de dados em JavaScript para gerenciar os gastos.
* **Atualização Dinâmica do DOM:** Interface atualizada em tempo real conforme as interações do usuário.
* **Validação de Formulários:** Limpeza e redefinição de campos após o envio dos dados.

## 📁 Estrutura do Projeto

```text
├── img/            # Ícones e imagens utilizados na interface
├── index.html      # Estrutura principal da página
├── styles.css      # Estilos visuais da aplicação
└── script.js       # Lógica e manipulação do DOM em JavaScript
```
